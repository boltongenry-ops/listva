# Как добавить новую запись

Этот журнал устроен максимально просто: записи лежат в папке `posts/` обычными текстовыми файлами в формате **Markdown**. Чтобы появился новый пост, нужно сделать два маленьких шага.

## Шаг 1. Создай файл записи

Создай файл в папке `posts/` с любым латинским названием и расширением `.md`, например:

```text
posts/moya-zapis.md
```

Внутри — обычный Markdown. Поддерживаются:

- **заголовки** (`#`, `##`, `###`);
- *курсив* и **жирный** текст;
- [ссылки](https://example.com) и изображения;
- списки и цитаты (`>`);
- блоки кода (тройные обратные кавычки).

## Шаг 2. Добавь запись в оглавление

Открой файл `posts/index.json` и добавь туда блок с описанием записи:

```json
{
  "slug": "moya-zapis",
  "title": "Название записи",
  "date": "2026-08-13",
  "excerpt": "Одно-два предложения, которые покажутся на главной.",
  "tags": ["тема", "ещё тема"],
  "readingTime": 2
}
```

> Поле `slug` должно совпадать с именем `.md`-файла (без расширения). Записи сортируются по дате автоматически — новые сверху.

## Всё

После этого запись появится на сайте сама. Никакой сборки не нужно — просто закоммить изменения и отправь их на GitHub.
