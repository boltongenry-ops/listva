# Листва 🌿

Личный журнал о важном — тёплый, медленный, органичный. Статический блог без сборки, размещённый на GitHub Pages.

## Как добавить запись

1. Создай файл `posts/<slug>.md` с текстом записи в формате Markdown.
2. Добавь запись в оглавление `posts/index.json`:

```json
{
  "slug": "moya-zapis",
  "title": "Название записи",
  "date": "2026-08-13",
  "excerpt": "Короткое описание для главной страницы.",
  "tags": ["тема"],
  "readingTime": 2
}
```

`slug` должен совпадать с именем `.md`-файла (без расширения). Записи сортируются по дате автоматически.

## Структура

```
listva/
├── index.html          # оболочка сайта
├── assets/
│   ├── css/style.css   # стили
│   └── js/main.js      # движок (роутер, markdown, настройки SITE)
├── posts/
│   ├── index.json      # оглавление записей
│   └── *.md            # сами записи
└── README.md
```

Настройки сайта (название, подпись, текст «О журнале») — в объекте `SITE` в начале `assets/js/main.js`.

## Локальный предпросмотр

Из-за загрузки файлов через `fetch` сайт нужно открывать через локальный сервер:

```bash
python -m http.server 8000
# → http://localhost:8000
```

## Деплой

Сайт размещён на GitHub Pages (ветка `main`, корень). Любой пуш в `main` обновляет сайт автоматически.
